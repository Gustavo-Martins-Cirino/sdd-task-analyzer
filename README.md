# sdd-task-analyzer

Implementação do módulo **TaskAnalyzer** guiada por especificação (SDD — *Specification-Driven
Development*), com código gerado por assistente de IA, validado por um *Test Harness* em pytest e
versionado com branches e Pull Requests.

> Repositório em construção. A especificação, o test harness e a implementação entram por Pull
> Request, nesta ordem: o contrato primeiro, os testes depois, o código por último.
